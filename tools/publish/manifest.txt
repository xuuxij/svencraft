# Svencraft export manifest: which files of the working tree go into the GitHub repo (read by export.py).
# Paths are relative to the project root, with '/' separators.
#   + <glob>     include the files matching the glob (* = within one folder, ** = any depth)
#   - <glob>     exclude matching files, whichever rule included them (git clones too)
#   git <dir>    a nested git clone: its tracked files as they are on disk (deleted ones skipped) plus the
#                untracked files git does not ignore; its submodules become gitlinks in the export repo
# A file is exported when it matches a + or git rule and no - rule. Everything else (run/'s engine package and
# generated assets, build folders, deps/, dl/, maps_src outputs) is rebuilt from these sources: docs/BUILDING.md.
